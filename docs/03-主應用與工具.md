# 03｜主應用與工具

文件狀態：現行程式已確認

盤點日期：2026-08-26

主入口：[`index.html`](../index.html)

## 1. View 結構

主頁目前有五個主要 view：

| View | 主要用途 | 內容來源 |
| --- | --- | --- |
| `home` | 工具入口與狀態摘要 | 根頁面 HTML/inline JS |
| `generator` | 版位生成器 | 根頁面 + `core/` + `blocks/`；含 bottom iframe |
| `exposure` | 曝光資源入口 | `jbp/jbpbn.html` iframe |
| `import` | 工單匯入、編輯、預覽與下載 | 根頁面 + schema renderer |
| `maint` | 版位維護、候選 schema 與全部資料下載 | 根頁面 + block loader |

切換通常由 `showView` 統一處理；嵌入頁面採 lazy-load 或 iframe ready 流程，避免首頁初始化時立即啟動全部子工具。

## 2. 首頁與導覽

主選單提供 Home、工單生成器、曝光資源、匯入工單、維護等入口。現行主選單與匯入工具列採線性 SVG icon：

- `fill:none`
- `stroke:currentColor`
- round line cap/join
- 主選單約 1.75～1.8px stroke

新增工具列 icon 時應優先重用既有 `lineIcon(name)` 或相同 SVG 規格，避免再次引入 emoji、填色 icon 或不同視覺語言。

## 3. 工單生成器

### 3.1 三個子分頁

## 4. 生成器到匯入工單

這是目前最容易被誤解的流程：

1. 使用者在生成器選版位、排順序、填資料。
2. 生成器 state 以 `group`、`slots`、`msbn` 等結構保存。
3. 生成器編輯中不會自動改寫匯入工單畫布。
4. 使用者按下匯入工單上方的「載入工單生成器版配」按鈕。
5. `loadGeneratorSelectionIntoImport` 將目前生成器選擇轉成匯入欄位。
6. 匯入畫布接手後，使用者可繼續獨立編輯文字、圖片、配色與順序。

這個手動邊界是刻意設計，不能在 `showView` 或 generator 每次 render 時恢復自動同步，否則會覆蓋匯入畫布上的後續編輯。

## 5. 匯入工單

### 5.1 輸入

- 自有 JSON / JSON 快照。
- 自有 XLSX。
- MSBN 工單欄位。
- Subarea 工單欄位。
- 生成器目前選擇（透過明確按鈕載入）。
- 圖片檔與匯入畫布快照。

### 5.2 主要區塊

| 區域 | 能力 |
| --- | --- |
| 左側欄 | 上傳工單、載入生成器版配、全部版位預覽、圖片 gallery、共用色彩 |
| 中央畫布 | 版位欄位預覽、文字/圖片編輯、依欄位串接多欄版配 |
| 右側工具列 | 文字欄位操作、圖片替換/編輯/刪除/重設、下載 PNG、編輯快照 |

### 5.3 解析與渲染

主要流程函式包括：

- `handleImportFile`
- `parseImportOwnJSON`
- `parseImportOwnJSONMsbn`
- `parseImportXlsxV2Workbook`
- `parseImportXlsx`
- `afterImportParsed`
- `renderImportColumns`

匯入後每個欄位會保留 `blockId`、`data`、`header`、`band`、`sourceKey` 等資訊，以便重新渲染與再次匯出。

### 5.4 畫布操作與同步

- `IMPORT_SYNC` 以 `lockUntil`、`canvasTimer`、`toolTimer` 避免畫布和右側工具列互相觸發無限 scroll feedback。
- 畫布與工具列會 snap 到同一個 current column。
- 匯入背景與 JBP 曝光資源文字可透過 shared localStorage key 做有限度同步。
- 匯入 state 會保存到 localStorage；維護頁的候選版位則以 memory context 為主，不應假設兩者會互相污染。

## 6. 匯出

| 匯出 | 主要函式 | 說明 |
| --- | --- | --- |
| 單一工單 JSON | `exportWorkOrderJSON` | 供自有格式重載與交換 |
| 單一工單 XLSX | `exportWorkOrderXlsx` | 使用 ExcelJS |
| 全部版位 XLSX | `exportAllPlacementsXlsx` | 維護/批次用途 |
| 匯入畫布 PNG | `downloadImportImage` | 使用 html-to-image；匯出前暫時將 strip scale 設為 1 |
| 編輯快照 | `buildImportSnapshot` | 包含欄位、圖片、主題、縮放與偏移 |

PNG 匯出會使用 `resolvedImportBg()` 作為背景，並在可用時注入 `BN_FONTS_EMBED_CSS`，以降低預覽與下載結果的字型差異。

## 7. 維護工具

維護頁會：

- 載入 active registry 的全部 blocks。
- 根據註冊 ID 去除最後一段，推導候選 schema 名稱。
- 載入未註冊但存在的候選 block。
- 以 `refImage` 與尺寸辨識重複或相近版位。
- 提供全部版位資料下載。

因此維護頁看到的數量可能大於主生成器的 active 數量；這是設計上的診斷能力，不代表所有實體 schema 都已正式上線。

## 8. 變更落點速查

| 需求 | 優先修改 |
| --- | --- |
| 新增/修正版位 | `blocks/{id}/block.json`、`blocks/index.js`，必要時同步 `manifest.json` |
| 改 renderer 通用行為 | `core/schema-renderer.js` |
| 改 block 載入/registry | `core/core-engine.js` |
| 改工單解析/匯出/匯入 UI | `index.html` 對應 inline 區塊 |
| 改共用圖片編輯行為 | `JS/image-layout.js`、`JS/editor-plugin.js` |
| 改吸底圖 | `bottom/src/`；不要直接改產生的 icon manifest |
| 改 JBP 共用功能 | `jbp/js/` 或 `jbp/jbpbn.html` |
| 改 JBP 單一版型 | `jbp/html/{layout}.html/.css/.config.css` |
| 改 PSD/CSS 生產規則 | `export/psd-css-toolkit/psdcss/` |
| 改 QA/量測 | `tools/` |
