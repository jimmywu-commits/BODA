## 1. 文件目的

本文件集是 BOD 工作台的工程交接與維護基準，涵蓋：

- 使用者可操作的工具與畫面。
- 前端執行模型、模組邊界與載入順序。
- 版位 schema、manifest、工單與專案檔資料格式。
- 主 BOD、吸底圖編輯器、曝光資源 JBP 三個子系統。
- PSD/CSS 產製、品質檢查、修正與預覽腳本。
- 視覺渲染、文字配色、圖片吸附、字型與匯出規則。
- 開發、維護、驗證、風險與後續改善建議。

文件以目前原始碼與 JSON 資產為依據；既有 README 與歷史紀錄保留為補充資料，不視為比現行程式更高的權威來源。

## 4. 原始碼權威層級

當不同文件描述不一致時，依下列順序判斷：

1. 執行時實際載入的 HTML/JS/CSS 與 `block.json`。
2. `blocks/index.js`、根目錄 `manifest.json`、`JS/config.json` 等註冊與設定檔。
3. 本文件集的盤點結果。
4. 子系統 README、架構說明與使用說明。
5. 歷史修正紀錄、備份檔與舊版說明。

原因是此專案目前採無 build 的靜態檔案架構，部分說明文件可能早於近期功能變更；新增功能時應同步更新本文件集。

## 6. 盤點方法與限制

本文件集以靜態檔案盤點、函式/資料結構追蹤、JSON 統計與既有工具清單為主。尚未把所有功能在瀏覽器逐一操作一遍，因此：

- 「現行程式已確認」代表可由檔案、程式流程或資料統計直接確認。
- 「需實機驗證」代表仍應在實際瀏覽器、HTTP server、使用者資料與外部 CDN 可用的條件下驗證。
- 備份檔、候選版位與歷史工具會明確標記，不與 active runtime 混為一談。
