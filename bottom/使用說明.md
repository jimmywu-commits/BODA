# 吸底圖便捷編輯器 — 使用說明

給實際做圖的人看的操作手冊。
想知道「為什麼這樣做」「怎麼改程式」請看 [README.md](README.md)（那份是給工程師的）。

---

## 這是什麼

做電商頁面底部那條促銷橫幅（**吸底圖**）的工具。

一條吸底圖有 2～5 組「icon + 文字」，每次要輸出 N 張圖，
**每張各反白一顆**（橘或紅）、其餘轉灰。以前用 PS 一張一張對位調色，
現在填好內容按一次匯出，N 張一起出來。

輸出規格固定 **1200 × 150 px PNG**，上方 20px 透明、下方 130px 白底。

---

## 開始使用

### 1. 取得檔案

跟同事要 GitHub 網址，然後：

- **會用 git**：`git clone <網址>`
- **不會用 git**：GitHub 頁面右上角綠色 **Code** → **Download ZIP** → 解壓縮

### 2. 打開

**直接雙擊 `index.html`**。不用安裝任何東西，不用架 server。

> ⚠️ **第一次開會等幾秒**，畫面會顯示「正在載入 ShopeeNotoSans 字體…」。
> 字體約 22MB（Medium + Bold 兩個字重），載完才會出現畫布。
>
> **這台電腦必須連得上網路。** 工具需要下載字體與兩個繪圖套件。
> 若停在紅色錯誤畫面，代表字體載入失敗 —— 此時**不會**讓你匯出，
> 因為那樣會產出錯誤字體的圖。確認網路後按「重新載入字體」。

## 一打開就會問你「這次的工單」

字體載完之後會先跳出一個對話框：

```
              開始製作吸底圖
   上傳本次的工單 .xlsx，系統會自動帶入
     每一條吸底圖的文案與 icon 名稱。

   ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
   │            📊               │
   │       上傳工單 .xlsx         │   ← 點一下選檔，或直接把檔案拖進來
   │  點擊選擇，或直接把檔案拖曳到這裡  │
   └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘

   [   略過   ]  [ 📂 載入進度存檔 ]
```

- **有工單就直接丟進來**，整份文案與 icon 一次填好，比自己一格一格打快得多。
- **要接續昨天的進度** → 按「📂 載入進度存檔」，選那份 `進度存檔.json`。
- **想從空白開始** → 按「略過」（按 Esc 或點對話框外面也一樣）。

> 這三件事在右側面板最上方一直都在，關掉之後隨時還能做。
> 開場先問只是因為「先匯工單」幾乎永遠是最省事的作法。

> **重新整理（F5）會再問一次。** 這是刻意的——重新整理通常就是想重來。

> 選錯檔案時對話框**不會關掉**，會直接把錯誤寫在卡片上，改選一次就好。

## 操作步驟

### 步驟 1：決定要做幾顆

右側面板 **「模板顆數」** → 選 2 / 3 / 4 / 5 顆。

### 步驟 2：選圖

每一顆的內容卡上有一顆**顯示縮圖的按鈕**，點下去會跳出素材選單：

- 上方有**搜尋框**，打關鍵字就會篩選
- 素材超過一個畫面時，**選單裡直接滾滑鼠或拖右側拉桿**就能往下看
- 點縮圖即選取，選單自動關閉
- 目前選中的那張會有橘框
- 要清空這一格就按 **「清除」**
- 按 **Esc** 或點旁邊空白處可關閉選單（**捲動側邊面板**也會關閉）

素材來自專案的 `img/` 資料夾，全公司共用同一份。

### 步驟 3：打文字

每顆下方的輸入框。右邊會顯示字數，例如 `3/5`。

**5 字是建議上限，不是硬限制**：

| 狀態 | 顯示 |
|------|------|
| 未滿 5 字 | 灰色字數 |
| 剛好 5 字 | 橘色字數 |
| **超過 5 字** | **紅色字數 + 輸入框紅框** |

超過仍然可以打、可以匯出，但畫布上的文字**會超出該格範圍撞到隔壁**——
那就是提醒你太長了。匯出按鈕上方也會再提醒一次。

> 中文一字算 1、英數半形算 0.5。所以「免運費」= 3、「Free」= 2。

### 步驟 4：決定反白哪一顆

每顆卡片左上角的 **「○ 設為反白」**。設定的是**預覽**要看哪一顆反白的效果，
**不影響匯出張數** —— 匯出一定是每顆各出一張。

### 步驟 5：選反白顏色

面板上方 **「反白顏色」** → 橘 `#ee4d2d` 或 紅 `#d0011b`。每條分頁各自獨立。

### 步驟 6：匯出

面板最底下（不用捲動，它固定在那）：

- **「匯出『吸底 1』的 N 張變體圖」** — 只匯目前這條
- **「匯出全部分頁」** — 有多條時才出現，zip 內依分頁分資料夾

下載下來是 **zip**，裡面有：

```
1-免運費.png        ← 第 1 顆反白
2-領折價券.png      ← 第 2 顆反白
3-天天簽到.png      ← 第 3 顆反白
進度存檔.json       ← 見下方
```

## 常用功能

### 從工單匯入（最省事的作法）

面板最上方 **「📋 匯入工單（xlsx / csv）」** → 選整份工單檔。

工具會自動找出吸底圖那一區，把**文案、icon 名稱、LOGO 標記**一次填好。
工單裡有幾條吸底圖就建幾個分頁。

匯入後會出現一行 **「匯入明細（N 項）」**，點開可以逐項核對抓到什麼。
**素材名稱對不上的會留空並列出來**，不會硬塞一張看起來像的給你。

> 工單裡寫的素材路徑（`G:\共用雲端硬碟\...`）**無法自動載入** ——
> 瀏覽器沒有讀取本機路徑的權限，這是安全限制。那些圖要自己用「⬆ 上傳」放進去。

### 進度存檔（做到一半要收工）

匯出的 zip 裡一定會附一份 **`進度存檔.json`**。

下次要接續編輯：面板上方 **「📂 載入進度存檔（JSON）」** → 選那個檔。
文字、選圖、顆數、分頁、反白顏色全部回來。

> **這份存檔可以直接傳給同事**，你上傳過的圖是內嵌在裡面的，
> 對方載入就看得到，不需要另外傳圖。

### 分頁（一次做好幾條）

最上方那排像瀏覽器分頁的東西。

- **＋** 新增一條
- 分頁上的 **×** 刪除（刪錯按 Ctrl+Z 救回來）
- 素材庫**跨分頁共用**，但文字、顆數、反白顏色各自獨立

### 放大檢視

想確認細節時：

| 操作 | 效果 |
|------|------|
| **Alt + 滾輪** | 以游標為中心放大縮小（和 PS 一樣） |
| 滾輪 | 平移 |
| 拖曳畫布 | 平移（按在哪裡都是平移，不會動到成品） |
| 右下角 **100%** | 看實際輸出大小 |
| 右下角 **符合視窗** | 整張看得完 |

**縮放只影響你看到的，匯出永遠是 1200×150。**

### 用文字代替圖（9.9、10.10 這種檔期）

節日檔期常常不放 icon，直接放日期數字。每一格旁邊的 **「T 文字」** 按鈕：

1. 按下去 → 該格變成輸入框，預設帶「9.9」，游標已經在裡面且全選
2. 直接打你要的數字（10.10、11.11、雙 12…），**畫布即時跟著變**
3. 要改回放圖，按旁邊的 **「× 改回選圖」**

字體是 **ShopeeNotoSans Bold**，跟 icon 一樣會依反白狀態變橘/紅或轉灰，
不用另外設定。

**一格只能是圖或字，不能兩者都有** —— 打了字原本選的圖會自動清掉，反之亦然。

> 字級固定 40px，這樣「9.9」和「10.10」擺在一起大小才一致
>（如果讓它自動填滿框，9.9 會比 10.10 大一半）。
> 只有真的塞不下才自動縮小；**縮到最小仍然放不下時輸入框會變紅框**，
> 那表示這串字太長，畫面上會溢出撞到隔壁。

> 這是**即時文字不是圖片**，所以隨時可以改、放大看也不會糊，
> 存檔裡只存那幾個字。明年 9.9 要改成 10.10，改 3 個字就好。

### 畫質（補銳化）

面板中間有一顆 **「✓ 已開啟補銳化」**，**預設就是開啟的，建議別關**。

瀏覽器畫文字時不會像 PS 那樣把筆畫「吸附」到像素格線上，所以同樣 22px 的中文，
不做處理的話會比 PS 做的軟一點。這顆開關就是在補這一段，icon 與文字都會套用，
**預覽和匯出看到的是同一個結果**。

> 唯一的副作用：灰階 LOGO 的邊緣會出現比 `#848484` 稍深一點的像素（銳化的本質，PS 也一樣）。
> 很介意的話可以關掉，關掉之後整體會軟一些。

### 一鍵把 icon 套到其他分頁

一份工單常常出好幾條吸底圖，**icon 幾乎一樣、只差一兩顆**，但每一條的文案不同。
所以有兩顆按鈕，**它們只搬 icon，下方的文案完全不會動**：

| 按鈕 | 位置 | 做什麼 |
|------|------|--------|
| **⧉ 把這條的 icon 全部套到其他 N 條** | 面板「套用到其他分頁」，就在**最後一格下面** | 這一條每一格的 icon 一次推到所有其他分頁的同一格 |
| **⧉ 這格套到其他分頁** | 每顆內容卡右下角 | 只推這一格 |

**建議流程**（廠商 LOGO 只要上傳一次）：

```
1. 匯入工單             ← 每條的文案都填好了
2. 在第 1 條把圖全部選好  ← 廠商 LOGO 在這裡上傳一次就好
3. 按「全部套到其他 N 條」 ← 其他條的 icon 一次到位，文案原封不動
4. 切到有差異的那條，手動換掉不一樣的那顆
```

第 4 步改完之後如果又想推給別人，用**「這格套到其他分頁」**，不要再按一次整組套用
——整組會把你剛剛手動改過的其他格也一起蓋掉。

> 只有**兩條以上**分頁時這兩顆按鈕才會出現。
>
> **來源是空的那一格，會把其他頁的同一格也清空。** 語意是「讓其他頁跟這頁一樣」，
> 不是「把有值的補過去」。按錯就 Ctrl+Z，整個動作只算一步。
>
> 其他分頁**顆數比較少**時只套得到的部分，顆數不會被改（訊息會告訴你少套了幾格）。

### 上傳自己的圖

每一顆旁邊的 **「⬆ 上傳」** → 選 `.svg` / `.png` / `.jpg` → 填名稱 →
按 **「加為一般 icon」**（橘鈕）或 **「加為廠商 LOGO」**（灰鈕）。

**兩者差別很重要：**

| | 反白時 | 未反白時 |
|---|---|---|
| **一般 icon** | 整顆變成橘/紅 | 整顆變成灰 `#848484` |
| **廠商 LOGO** | **保持品牌原色** | 轉成灰階（看得出形狀） |

廠商的 LOGO **一律選灰鈕**，不然品牌色會被蓋掉。
按錯了直接 **Ctrl+Z**，一次就完整還原。

> **有高解析度的原檔就直接上傳原檔，不用自己先縮小。**
> 工具會自己把大圖分次縮到 107×58 該有的像素數（一步縮 6 倍會把細筆畫削斷，
> 廠商 LOGO 的英文小字最明顯）。自己先縮成小圖反而是把這道處理跳過去。

> ⚠️ **上傳的圖不會被記住，重新整理就消失。**
> 這是刻意的。要讓某張圖永久留在素材庫，請走「加新素材」那一節。
> 但**匯出的存檔裡有內嵌這張圖**，所以交接不會掉圖。

### 修圖（裁切 / 去白底）

選好圖之後旁邊會出現 **「✏ 編輯」**：

- **裁切** — 拉框後按「✂ 裁切」
- **⊕ 加透明邊** — 圖太滿想留白時用
- **⊖ 裁到內容** — 去掉多餘的透明邊
- **去白底（保留內部白色）** ← 多數 LOGO 用這個。只打掉跟外框連通的白，LOGO 內部的白字會留著
- **連內部白色一起去** — 白底黑線稿用這個
- 容許度滑桿 — 白底不夠純時往右調
- **↩ ↪** — 編輯器內部的復原/重做

編輯結果會存成新的一筆，**不會改到原本那張**。

## 遇到問題

| 狀況 | 怎麼辦 |
|------|--------|
| 停在「正在載入字體」很久 | 檢查網路。公司網路可能擋了 `jimmywu-commits.github.io` |
| 紅色「字體載入失敗」 | 確認網路後按「重新載入字體」。**這時不能匯出是刻意的** |
| 按匯出跳出「有 N 個 icon 圖檔無法載入」 | 某張上傳的 SVG 少了 `xmlns` 屬性。換一張圖，或請工程師修 |
| 畫布上某格是虛線空框 | 那格沒選圖，或圖檔壞了 |
| 文字超出去撞到隔壁 | 字太長了。縮到 5 字內 |
| 上傳的圖重新整理後不見了 | 正常，見上方說明。要永久保留請走「加新素材」 |
| 下載的圖比 PS 做的糊 | 先確認面板「畫質」的**補銳化是開啟的**（預設就是開的）。瀏覽器畫文字沒有 hinting，PS 有，這個開關就是補這一段 |
| 下載的圖是不是被壓縮了 | 沒有。匯出是無損 PNG（整張只有 299 色、約 15KB）。看起來糊多半是看圖軟體把 1200×150 放大到滿版了，用 100% 檢視才是真的 |
| icon 看起來有點糊 | icon 框只有 107×58，本來就小。換一張構圖更簡單的素材比加後製有效 |
| 想拖曳微調某一顆的位置 | 已移除。位置一律由模板決定，這樣同一批圖之間才對得齊 |

## 加新素材（要讓全公司都拿到）

這一步需要**會用 git**，通常請工程師或熟悉的人做一次。

```
1. 把圖檔（PNG / JPG / SVG）放進專案的 img/ 資料夾
2. 開終端機，在專案資料夾執行：
      node tools/build-icon-manifest.js
3. git add img/ src/icons/manifest.js
   git commit -m "新增素材：XXX"
   git push
```

其他人 `git pull` 之後重新打開 `index.html` 就有了。

**素材檔的要求：**

- **鏤空處必須是真正的透明像素**，不能畫成白色。
  白色會跟著被染成橘/灰，鏤空效果就沒了。
- **SVG 一定要有 `xmlns="http://www.w3.org/2000/svg"`**，
  少了它瀏覽器會拒絕載入，而且匯出會被擋下。
- **檔名就是素材名稱，也是它的識別碼。**
  改檔名等於換一顆新素材，**用過這張圖的舊存檔會找不到它**。
  要改名請確認沒有還在用的存檔。

## 一定要知道的三件事

1. **匯出永遠是 1200×150**，跟你把畫布放多大無關。
2. **廠商 LOGO 上傳時要按灰色那顆按鈕**，按錯品牌色會被蓋掉。
3. **收工前記得留著匯出的 `進度存檔.json`**，那是唯一能接續編輯的東西。
